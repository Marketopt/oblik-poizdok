# Stage 4 — iPhone / GitHub Pages

## Розгортання без комп’ютера
1. Створіть **приватний або публічний** репозиторій GitHub для проєкту (перевірте доступність Pages для вашого тарифу; публічний репозиторій зазвичай найпростіший).
2. Завантажте **вміст папки `trip-app`** до кореня репозиторію, включно з `.github/workflows/deploy-pages.yml`.
3. В GitHub → Settings → Pages → Build and deployment виберіть **GitHub Actions**.
4. Вкладка Actions → `Build and deploy iPhone PWA` → Run workflow, якщо запуск не відбувся автоматично.
5. Дочекайтеся **зеленого** результату. Якщо збірка не пройшла — не встановлюйте застосунок, спочатку виправте помилки з логу.
6. Відкрийте HTTPS-адресу з Settings → Pages у **Safari на iPhone**, натисніть Поділитися → На Початковий екран → Додати.
7. Для перевірки офлайн: один раз відкрийте встановлений застосунок з інтернетом, потім увімкніть авіарежим та повторно відкрийте.

## Важливо
- Це вихідний проєкт із CI-публікацією; **локальна компіляція не підтверджена**, бо npm registry недоступний у середовищі підготовки.
- **Посилання ще не створене**: потрібні GitHub-репозиторій і успішне виконання Actions.
- Дані зберігаються в IndexedDB **на конкретному iPhone / у конкретному встановленні**, не синхронізуються між пристроями.
- Регулярно експортуйте JSON у «Файли» / iCloud Drive. Перед оновленнями створюйте копію.
- PIN із 6 цифр — захист інтерфейсу, **не шифрування локальної бази**.
- Не публікуйте свої реальні резервні копії JSON у репозиторії.
