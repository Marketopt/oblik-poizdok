# Stage 3 — стан перевірки

- ZIP Stage 2 знайдено та розпаковано.
- Виправлено верхню межу календаря завершення звітного періоду.
- Відновлення JSON тепер записує дані в IndexedDB до повідомлення про успіх.
- Service Worker оновлено до v3: мережевий пріоритет для HTML, кешовані файли для офлайн.
- Додано автоматизовані тести розрахунків: `npm run test:logic`.
- `npm install` не завершився через тайм-аут доступу до npm; `npm run build` **не перевірено успішно**.
- Тест на реальному iPhone/Safari та HTTPS-публікація **не проводилися**.
- `dist/` відсутній: ZIP містить вихідний код, а не готовий сайт для хостингу.

## Збірка на комп’ютері або CI

```bash
npm install
npm run test:logic
npm run build
```

Після успішної збірки опублікуйте вміст `dist/` на HTTPS-хостингу зі статичним розміщенням та SPA fallback на `index.html`.
Перед робочим використанням перевірте експорт/імпорт JSON, перезапуск, офлайн-режим та оновлення PWA на iPhone.
