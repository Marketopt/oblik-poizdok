# Stage 5 — Підсумок

Чотири фінансові картки з іконками: зарплата, пальне +30%, понаднормові, готель; нижче загальна сума. Логіка PIN, IndexedDB, резервних копій і PWA не змінена.

Вміст цього ZIP слід розмістити у корені репозиторію (без зовнішньої папки). Перед оновленням експортуйте JSON. Перевірки: `npm install`, `npm run build`, `npm run test:logic`, Safari та офлайн.
